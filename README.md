# ai별 특징 정리

## ChatGPT
- 비추론 모델은 재미있는 말투를 쓰지만 코딩 관련해서는 사용하지 못할 정도로 멍청함
- 추론 모델은 매우 긴 코드를 생성하는 것에는 적합하지만 그래도 멍청해서 코딩을 딱히 잘하지는 못함
- 음성 대화 모드는 매우 현실적이지만 지능이 조금 낮음
- 검색을 잘하긴 하는데 영어로 검색하라고 시켜야 영어로 검색해서 조금 불편함
- 일을 열심히 하는게 아니라 대충 때우려고 함
## Claude
- 추론모델이든 비추론 모델이든 모두 코딩을 잘함
- 추론모델과 비추론 모델간의 지능 차이가 별로 없음
- 코딩을 매우 잘하지만 최대 토큰이 적어서 긴 코드를 잘 생성하지 못함
- 대화를 오래 하다보면 코드에 문법오류를 많이 냄
- 디자인을 엄청 잘함
## Gemini
- 이미지 및 영상 분석을 잘함
- 2.5 Pro는 코딩을 잘한다는 말이 많지만 실사용 결과 코딩은 클로드 3.7이 더 잘함
- google 서비스들과 통합이 잘되긴 하는데 모든 ai가 검색을 이용할 수 있는건 아니라서 조금 불편함
- 검색을 멍청하게 함
## Deepseek
- 상남자식 해결을 잘함(예: 프로그램이 잘 작동하게 하기위해 모든 프로그램을 삭제하고 필요한것만 다시 설치)
- 검열이 별로 없어서 난독화된 코드 해독, 취약점 찾기 등을 쉽게 할 수 있음
- 최대 토큰 수가 좀 적어서 긴 코드는 생성하지 못함
- 디자인을 잘하는 편임
- 검색할때 매우 많은 사이트를 찾아봐서 편함
- 일을 열심히 하기는 하는데 좀 멍청함
## Qwen
- 일상적인 대화에만 적합함
- 코딩을 시키지 않는게 좋음
- 검색도 시킨 언어로만 해서 잘 하지도 못함
- 모델이 작아서 로컬로 돌리기는 좋음
- 작은 모델도 한국어 잘함
- GPT 4o 개선판 느낌
## Grok
- grok 3 (think킨 버전)는 코딩이 나쁘지 않음 그런데 이게 어딘가 멍청한 느낌이 느껴짐
- 검열이 거희(그냥 아예 없는건가) 없어서 법을 위반할것같은 일도 가능함
- 검색을 은근히 잘하기는 하는데 엄청 잘하는것 까진 아님
## Manus
- 너무 비쌈
- 확실히 성능이 좋기는 한데 코드를 일부만 수정하는것이 아니라 처음부터 다시 생성해서 덮어씌우는 경우가 많아서 2200줄 이상 코드는 안 주는게 좋음
- 검색을 잘하기는 하는데 chatgpt 딥리서치보다 약간 떨어지는 느낌
- 특정 사이트를 잡고 분석하는것을 잘함
- 디자인도 잘하기는 하는데 그냥 클로드랑 비슷함(당연히 비슷한게 정상임)
- 다른 중국 ai들처럼 어떻게든 사용자가 시킨 일은 해결하려고 해서 좋음
## perplexity
- 검색을 잘한다고는 하는데 이거 쓸바에 gpt 검색 씀
- 당연히 코딩에는 부적합함
- 뭔가 멍청한 느낌이 있음
## Copilot
- 그닥 똑똑하지 않음
- 이게 검색을 그닥 잘하는것도 아니고 코딩을 잘하는것도 아니고 말투가 자연스러운것도 아니고 사진 및 영상 분석을 잘하는것도 아니라서 무슨 어디 딱히 쓸대도 없음
- 추론 기능을 키면 어느정도 쓸모있어 지지만 그래도 그냥 다른 ai쓰는게 더 효율적임
